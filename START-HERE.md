# Start here

This folder is your Dutch study vault. It works locally before GitHub publication.

## Open in Obsidian now

1. Extract the complete ZIP, retaining the hidden `.obsidian` folder.
2. Install Obsidian, choose **Open folder as vault**, and select this `dutch-study` folder.
3. Open README. Use global search or the vocabulary, grammar and chapter links.

No community plugins or Python are needed just to study.

## Finish GitHub setup

GitHub rejected creation of the private repository because the connection lacks `CreateRepository` permission. No remote repository or tasks were created.

You can create an empty private repository named `dutch-study` under `brickwalllegend2000`, grant the connected GitHub app access, and give the agent its URL to finish. Or follow [publishing instructions](docs/PUBLISH.md) to run the prepared script with your own GitHub CLI login.

The script publishes the vault, creates three milestones and five tasks, installs labels and attempts a Project board. The Actions workflow validates the library after pushing. Remote execution remains unverified until publication succeeds.
