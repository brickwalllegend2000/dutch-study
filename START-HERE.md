# Start here

This folder is your Dutch study vault. It works locally before GitHub publication.

## Open in Obsidian now

1. Extract the complete ZIP, retaining the hidden `.obsidian` folder.
2. Install Obsidian, choose **Open folder as vault**, and select this `dutch-study` folder.
3. Open README. Use global search or the vocabulary, grammar and chapter links.

No community plugins or Python are needed just to study.

## Finish GitHub setup

The vault is published to the private repository `brickwalllegend2000/dutch-study`. The five starter tasks exist as GitHub Issues with their status/type labels. The three milestones and a Project board could not be created through the connected GitHub tools; add them by following [publishing instructions](docs/PUBLISH.md) (optional). The Actions workflow validates the library on each push.
