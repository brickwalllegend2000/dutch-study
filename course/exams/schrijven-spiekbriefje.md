## 1. Opbouw per tekstsoort

*Structure per text type.*

| Tekstsoort | Structuur | Vaste zinnen |
| :--- | :--- | :--- |
| Formulier *(form)* | Vul elk veld in, in de volgorde van het formulier | — |
| Briefje, formeel *(formal short note: school, work)* | Plaats + datum → aanhef → de gevraagde punten → afsluiting → volledige naam | Geachte meester, … / met vriendelijke groeten, |
| Briefje, informeel *(informal note: family, friends, neighbours)* | Plaats + datum → aanhef → de gevraagde punten → afsluiting → voornaam | Beste …, / Hallo …, / tot morgen, / tot vanavond, |
| Appje *(chat message)* | Kort: geen aanhef, kleine vragen, direct antwoorden | Hoi … / Fijn! Tot straks! |
| E-mail, formeel *(formal email)* | Onderwerp → aanhef → beginzin → inhoud → slotzin → afsluiting + naam | Beste …, / Ik hoor graag van u. / Bedankt voor uw tijd! / met vriendelijke groeten, |
| E-mail, informeel *(informal email)* | Zelfde structuur, met je/jij en Groetjes | Hallo …, / Bedankt voor je e-mail! / Groetjes |
| Tekst over vroeger *(text about the past)* | Imperfectum: was, had, woonde, vond, zag er … uit | Ik woonde vroeger … / Het huis zag er klein uit, maar … |

## 3. Zinsbouw-formules

*Sentence-building formulas.*

| Structuur | Formule | Voorbeeld |
| :--- | :--- | :--- |
| Hoofdzin (SVO) *(standard main clause)* | subject + verbum (positie 2) + tijd – manier – plaats | Elke ochtend studeer ik mijn woordenschat. |
| Inversie *(inversion: element up front)* | extra element vooraan + verbum + subject | Morgen begint de les om 10 uur. |
| omdat (SOV) *(subordinate clause)* | omdat + subject + rest + alle werkwoorden achteraan | Het is koud, omdat het raam kapot is. |
| want *(because: main-clause order)* | want + gewone hoofdzin (SVO) | Ik blijf thuis, want ik ben ziek. |
| Modaal verbum *(modal verb)* | subject + moet/kan/mag/wil + rest + infinitief achteraan | Je moet de hele dag in bed blijven. |
| Perfectum *(present perfect)* | hebben/zijn + volt. deelwoord (helemaal achteraan) | Vorige week heb ik 30 minuten gestaan. |
| Vaste tijden *(fixed time expressions)* | 's morgens / 's middags / 's avonds / 's nachts · in de voormiddag / in de namiddag | 's Avonds drink ik geen koffie. |

## 4. Spellingregels (formulier)

*Spelling rules for forms.*

- Voornaam en achternaam met een hoofdletter *(first and last name with a capital)*
- Straatnaam met een hoofdletter *(street name with a capital)*
- Postcode: vier cijfers en twee hoofdletters (1234 AB) *(four digits and two capitals)*
- Woonplaats met een hoofdletter *(city name with a capital)*
- Telefoonnummer: tien cijfers *(ten digits)*

## 5. Vink-lijst voor op het examen

*Final check before handing in.*

- Alle punten uit de opdracht beantwoord? Tel ze na. *(answered every point? count them)*
- Aanhef, afsluiting en je naam eronder? *(salutation, sign-off and name)*
- Minimum aantal zinnen gehaald? *(reached the minimum sentence count)*
- Werkwoord op positie 2, ook na inversie? *(verb in second position, also after inversion)*
- Nog één keer herlezen. *(read it through once more)*
