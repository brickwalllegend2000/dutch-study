## Can-do goals (Dit kan ik!)

Self-evaluation from coursebook p. 66. For each goal, decide whether you can do it alone, with help or not yet. Examples are in the [table of contents](../sources/pages/401f89e5e0fc8109a7fce9d6ce0656e9.md).

- Ik kan informatie halen uit een artikel over een citytrip.
- Ik kan zeggen wat je (in een stad) kan doen.
- Ik kan een bericht over een citytrip sturen naar familie en vrienden.
- Ik kan zeggen wat ik gedaan heb.
- Ik kan zeggen wat ik ga doen.
