## 1. Core Vocabulary (Woordenschat)

### Transportmiddelen (p. 114)

| Voertuig (ev / mv) | Variant | Betekenis / Voorbeeld |
| --- | --- | --- |
| **de fiets** / de fietsen | de elektrische fiets (e-bike) | Ik ga elke dag met de fiets naar het werk. |
| **de auto** / de auto's | | Met de auto sta je vaak in de file. |
| **de bus** / de bussen | | De bus stopt vlak voor mijn deur. |
| **de tram** / de trams | | In Gent en Antwerpen neem ik vaak de tram. |
| **de trein** / de treinen | | De trein is comfortabel om te lezen. |
| **de metro** / de metro's | | In Brussel neem ik de metro. |
| **de step** / de steps | de elektrische step | De step is handig voor korte afstanden. |
| **de bromfiets** / de bromfietsen | de scooter | Hij rijdt met een bromfiets. |
| **het vliegtuig** / de vliegtuigen | | Vliegen is slecht voor het klimaat. |
| **de boot** / de boten | de veerboot | We nemen de veerboot naar het eiland. |

### Infrastructuur en openbaar vervoer (p. 115)
- **het station** / de stations: "We spreken af aan het station van Gent-Sint-Pieters."
- **de halte** / de haltes: "Aan welke bushalte moet ik afstappen?"
- **het perron** / de perrons / **het spoor**: "De trein naar Brugge vertrekt van spoor 4."
- **het fietspad** / de fietspaden: "Er ligt een breed en veilig fietspad langs de vaart."
- **de file** / de files: "**in de file staan**" ("Ik sta al een halfuur in de file op de E40.")
- **de vertraging** / de vertragingen: "**vertraging hebben**" ("De trein heeft 15 minuten vertraging.")
- **het ticket** / het biljet / **het abonnement**: "Ik heb een maandabonnement voor de trein."
- **de passagier** (de reiziger) / **de chauffeur** (de bestuurder)

### Verba en uitdrukkingen (p. 115)
- **overstappen**: "Moet ik ergens overstappen?" — "Ja, je stapt over in Brussel-Zuid." *(separabel)*
- **instappen / uitstappen**: "Iedereen stapt in." *(separabel)*
- **meenemen**: "Mag ik mijn fiets meenemen op de trein?" *(separabel)*
- **rechtstaan**: "Er waren geen zitplaatsen vrij, dus ik moest rechtstaan."
- **missen**: "Ik heb de aansluiting gemist."
- **te voet gaan / wandelen**: "Het centrum is autovrij, we gaan te voet."

## 2. Conversational Frames (Spreekpatronen, pp. 115, 124)

### Voorkeuren en redenen motiveren
- "Welk transportmiddel gebruik je het vaakst?"
- "Ik neem **het liefst** de fiets, **omdat** het gezond en milieuvriendelijk is."
- "Ik reis **liever** met de trein dan met de auto, **want** dan kan ik rustig een boek lezen."
- "De auto is handig voor boodschappen, maar je verliest veel tijd in de file."

### Voor- en nadelen vergelijken
| Eigenschap | Voordeel | Nadeel |
| --- | --- | --- |
| **Fiets** | Milieuvriendelijk, gezond, goedkoop, geen file | Koud bij regenweer, gevaarlijk bij druk verkeer |
| **Trein** | Comfortabel, snel over lange afstanden, ontspannend | Soms vertraging, volle wagons tijdens de spits |
| **Auto** | Flexibel, gemakkelijk voor bagage | Duur (benzine, parking), vermoeiend, files |

### Een spraakbericht inspreken bij vertraging (p. 124)
- "Dag Lisa, ik ben onderweg naar ons afspraakpunt. Mijn trein had helaas een kwartier vertraging en ik heb mijn aansluiting gemist. Ik kom ongeveer 20 minuten later aan. Tot zo meteen!"

## 3. Grammar Focus (Grammatica, pp. 116–117)

1. **Onregelmatige trappen van vergelijking:** [Comparisons](../../wiki/grammar/comparisons-equal-comparative-and-superlative.md)
   - **goed** → **beter** → **best** (*de trein is beter voor het milieu*)
   - **veel** → **meer** → **meest** (*de meeste mensen nemen de fiets*)
   - **weinig** → **minder** → **minst** (*de step verbruikt het minst*)
   - **graag** → **liever** → **liefst** (*ik fiets graag, maar ik wandel liever*)
2. **Woordvolgorde: normale volgorde vs. inversie:**
   - Normale volgorde: *Ik neem elke ochtend de bus.*
   - Inversie (tijd eerst): *Elke ochtend **neem** ik de bus.*
3. **Verbindingswoorden: want vs. omdat:**
   - [Joining sentences: want, en, maar and of](../../wiki/grammar/joining-sentences-want-en-maar-and-of.md):
     - "Ik neem de bus, **want** het **regent** pijpenstelen."
   - [Because: omdat and subordinate clauses](../../wiki/grammar/because-omdat-and-subordinate-clauses.md):
     - "Ik neem de bus, **omdat** het pijpenstelen **regent**."

## 4. Dit kan ik! (Self-Assessment Checklist, p. 124)

- [ ] **Mijn transportgewoonten toelichten**: Ik kan vertellen hoe ik naar school of het werk reis en waarom.
- [ ] **Transportmiddelen vergelijken**: Ik kan de plus- en minpunten van fiets, trein, auto en bus formuleren met *beter, liever, sneller, goedkoper*.
- [ ] **Aankondigingen in het station begrijpen**: Ik versta mededelingen over spoorveranderingen en vertragingen.
- [ ] **Een voicemail of spraakbericht inspreken**: Ik kan een helder bericht achterlaten als ik te laat kom door file of vertraging.

## 5. Speaking Practice (Spreekopdrachten)

1. **Presentatie (2 minuten):** Wat is jouw ideale manier van reizen? Vergelijk je huidige transportmiddel met een alternatief en leg uit wat de overheid volgens jou moet verbeteren aan het fietspad of openbaar vervoer.
2. **Audiobericht oefening:** Spreek op je smartphone een audioboodschap in voor je docent waarin je uitlegt dat je bus pech heeft en hoe laat je verwacht aan te komen.
