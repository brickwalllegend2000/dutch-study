## geen or niet?

| What do you negate? | Use | Example |
| --- | --- | --- |
| *een* + noun | geen | Er is een lift. → Er is **geen** lift. |
| Noun without an article | geen | Er is centrale verwarming. → Er is **geen** centrale verwarming. |
| *elke dag*, *graag* | niet before it | Ik neem **niet** elke dag de bus. · Ik woon **niet** graag in het centrum. |
| A preposition phrase | niet before it | Ik woon **niet** op de derde verdieping. |
| The verb | niet after it | Hij begrijpt het woord **niet**. (master grammar reference) |

## er is / er zijn

Start with *er* when the real subject is not specific (with *een*, *geen*, a number or no article) and comes later in the sentence. This is common in descriptions.

| Subject | Pattern | Example |
| --- | --- | --- |
| One thing | Er + is | Er is een badkamer met douche. |
| More than one | Er + zijn | Er zijn twee slaapkamers. |
| Negative | Er + is/zijn + geen | Er is geen berging. |
| Position verb | Er + staat / ligt / hangt | Er hangt een schilderij aan de muur. |

## Position verbs: staan, liggen, hangen, zitten

| Verb | Used for (vocabulary notes) | Example |
| --- | --- | --- |
| staan | upright things, things on legs | Er staat een kast tegen de muur. |
| liggen | flat things | Er ligt een dik tapijt op de vloer. |
| hangen | things hung on a wall or ceiling | Er hangt een schilderij aan de muur. |
| zitten | things inside a closed space | De kat zit in de doos. · In de rugzak zit een laptop. |

With a plural subject, use the plural verb: *Er hangen gebloemde gordijnen. In de zetel liggen oranje kussens.*

## Watch out

- ✗ Er is niet een lift.† → ✓ Er is geen lift.
- ✗ Er is twee slaapkamers.† → ✓ Er zijn twee slaapkamers.
- ✗ Ik woon op niet de derde verdieping.† → ✓ Ik woon niet op de derde verdieping.
- ✗ Er hangt gebloemde gordijnen.† → ✓ Er hangen gebloemde gordijnen.
