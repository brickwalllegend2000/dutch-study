# 🧩 Combined projects

> Preserved import snapshot, 2026-10-23. Not maintained as canonical study data.

[Original Notion page](https://app.notion.com/p/401f89e5e0fc81c787f4cf27dc5cb151?pvs=204) · [Exact retrieval payload](../notion/401f89e5e0fc81c787f4cf27dc5cb151.json)

Three writing projects that combine chapters 1–8. Each project has two writing tasks and one warm-up drill, so every grammar guide gets used in a realistic text.

## How it works

**Pick a project**
Start with the one closest to the chapters you want to revise.

**Do the exercises in order**
Each page has the task, words, a grammar checklist, a plan, a writing box and a self-check.

**Compare with the model**
Open the toggle at the end only after you have written your own text.
