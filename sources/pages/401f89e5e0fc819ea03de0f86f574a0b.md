# Because: omdat and subordinate clauses

*Omdat / bijzin*

[Grammar guide](401f89e5e0fc819da383d5825749b371.md)

**Omdat** means because. It introduces a subordinate clause giving the reason for something.

## One verb in the reason

Move the conjugated verb to the end of the omdat clause.

**Main clause + omdat + subject + other information + verb.**

- **Ik kan niet naar de les komen, omdat ik hoofdpijn heb.** — I can’t come to class because I have a headache.

This combines the archive’s Asuka conversation with its instruction to use omdat.

## More than one verb

Keep the verbs together at the end of the reason. The archive gives this exact model:

**Ik kan morgen niet komen, omdat ik moet werken.**

Here **moet werken** is the verb group. Learn this example as a pattern; do not move moet back into normal main-clause position after ik.

## Compare want and omdat

Both can give a reason, but their word order differs.

- **Ik kan niet komen, want ik heb hoofdpijn.**
- **Ik kan niet komen, omdat ik hoofdpijn heb.**

The archive already contrasts want/omdat and includes **Ik heb hoofdpijn** in the message exercise.

## Try it

Join the two ideas using omdat.

1. Ik kan niet naar de les komen. Ik heb hoofdpijn.
2. Ik kan morgen niet komen. Ik moet werken.

Answers

1. **Ik kan niet naar de les komen, omdat ik hoofdpijn heb.**
2. **Ik kan morgen niet komen, omdat ik moet werken.**
